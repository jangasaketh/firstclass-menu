# First Class Dosa Bar website

A single-page restaurant website for First Class Dosa Bar: menu, online order tray, filter coffee section, loyalty punch card, locations and table booking.

Everything is in `index.html` (HTML, CSS and JavaScript in one file). No build step is needed.

## Run it locally
Double-click `index.html` to open it in any browser.

## Put it online with GitHub Pages (free)
1. Create a new public repository on GitHub, for example `first-class-website`.
2. Upload `index.html` and `README.md` (Add file > Upload files > Commit changes).
3. Go to Settings > Pages.
4. Under "Build and deployment", set Source to "Deploy from a branch", Branch to `main`, folder `/ (root)`, then Save.
5. After a minute or two your site is live at `https://YOUR-USERNAME.github.io/first-class-website/`.

## Before launch, replace
- Outlet addresses and phone numbers (search for "Station Road" and "+91 00000")
- Menu items and prices (the `MENU` list inside the `<script>` near the bottom)
- Social and delivery links in the footer
- Ordering and booking currently show confirmations only; connect them to your ordering system or WhatsApp Business to receive real orders
